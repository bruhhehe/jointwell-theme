# Jointwell theme

Shopify theme for Jointwell. Base: Shopify Dawn 16.0.0 (unmodified on `main`).

- `main`: clean Dawn base. Connect this branch to an **unpublished** theme in Shopify (Online Store > Themes > Add theme > Connect from GitHub).
- `jointwell-rebuild`: all Jointwell work (sections/jw-*, snippets/jw-*, assets/jw-*). Connect this to a second unpublished theme for preview.

Planning and copy live in `jointwell-build/`. No secrets are committed to this repo.
